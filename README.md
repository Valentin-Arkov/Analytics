## Работа в Colab

Задания по анализу данных мы выполняем в Google Colab. "Колаб" - это "ко-лаборатория", то есть "лаборатория для совместной работы". Здесь мы знакомимся с технологией анализа данных и с технологией организации совместной работы. 

Некоторые студенты на первых порах делают типичные ошибки. Это затрудняет совместное использование облачного блокнота и создает дополнительную работу. Лучше сразу сделать правильно, чем несколько раз переделывать. 

Вот наши рекомендации по грамотному использованию облачной технологии:

- выполняем работу в Колабе и сохраняем блокнот со всеми графиками и результатами вывода на экран - иначе преподавателю придется запускать каждую ячейку на выполнение и тратить в 10 раз больше времени на проверку. Блокнот – это не просто программа, а еще и весь вывод на экран.

- открываем доступ на чтение - иначе преподаватель не сможет увидеть вашу работу: нажимаем кнопку Share - Поделиться для всех по ссылке – Anyone with the link – Роль: Читатель/Просмотр – Role: Viewer и копируем ссылку – Copy link - чтобы получить работающую ссылку на чтение тетрадки в Колабе – не нужно копировать ссылку из строки адреса в браузере/ в результате ссылка обычно заканчивается параметром sharing – совместный доступ. Пример ссылки: https://colab.research.google.com/....?usp=sharing

- не нужно загружать блокнот IPYNB на облачный диск - это лишние действия и для студента, и для преподавателя. Неправильная ссылка будет выглядеть так: https://drive.google.com/drive/folders/..... Лучше просто открыть доступ.

# "Битые" ссылки - broken links

Чтобы поделиться ссылкой на файл в облаке, нужно при загрузке нажать кнопки Поделиться и Скопировать ссылку. 
В результате, в буфере обмена будет ссылка типа https://disk.yandex.ru/d/zF3N0SQWDZUhlw.

Но если открыть файл на просмотр/редактирование и скопировать ссылку из строки адреса браузера, получим длинную строчку типа https://disk.yandex.ru/edit/disk/disk%2F2024%2F%D0%9F%D0%98-%D0%91%D0%90%D0%A1-%D0. Такая ссылка не будет работать.

Рекомендуем перед отправкой ссылки проверить ее работоспособность. Например, можно открыть ссылку в другом браузере, где вы не авторизованы на облачном диске.
